# 04 — Python & Data Tools

The hands-on foundation both the [[data-science/index|Data Scientist]] and [[machine-learning/index|ML Engineer]] paths stand on: the Python numeric stack. Part of [[machine-learning/00-foundations/index|00-foundations]].

These are **practice notes** — code-heavy, meant to be typed out and run, not just read. They're the *how-to* companion to two more conceptual notes elsewhere: the [[machine-learning/01-foundations-of-ml/02-the-ml-toolkit|ML Toolkit]] landscape (what each library is *for*) and the [[data-science/05-data-visualization|Data Visualization]] principles (which chart, and honesty). 2. [[machine-learning/00-foundations/04-python-and-data-tools/02-numpy|02 — NumPy]] — **[Beginner → Intermediate]** — arrays, vectorization, and broadcasting: the mental shift from loops to array thinking
3. [[machine-learning/00-foundations/04-python-and-data-tools/03-pandas|03 — pandas]] — **[Intermediate]** — the DataFrame: loading, selecting, grouping, joining, and cleaning real data
4. [[machine-learning/00-foundations/04-python-and-data-tools/04-visualization-basics|04 — Visualization Basics]] — **[Intermediate]** — matplotlib and seaborn, hands-on

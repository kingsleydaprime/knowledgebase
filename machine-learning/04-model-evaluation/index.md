# 04 — Model Evaluation

Model evaluation is checking how good a model really is, on data it has never seen. A model can look perfect on the data it learned from and still fail on new data, so this is how you tell a real result from a number that only looks nice.

Start at lesson 1. The three metrics lessons build on each other.

1. [[machine-learning/04-model-evaluation/01-evaluation-metrics-1|01 — Evaluation Metrics 1]] — the confusion matrix, and accuracy, precision, recall and F1-score
2. [[machine-learning/04-model-evaluation/02-evaluation-metrics-2|02 — Evaluation Metrics 2]] — judging a model's probabilities: log loss, the ROC curve and AUC
3. [[machine-learning/04-model-evaluation/03-evaluation-metrics-3|03 — Evaluation Metrics 3]] — metrics for predicted numbers: MAE, MSE, RMSE, R² and MAPE
4. [[machine-learning/04-model-evaluation/04-overfitting-and-regularization|04 — Overfitting and Regularization]] — when a model memorises instead of learning, and how to stop it
5. [[machine-learning/04-model-evaluation/05-validation-and-tuning|05 — Validation and Tuning]] — cross-validation, and finding a model's best settings fairly

When you finish, try the past paper in the [[machine-learning/ssg-535-question-bank|SSG 535 question bank]].

## How to use this

Don't read the answers first. Cover them, answer out loud, *then* compare — recognition feels like knowledge and isn't. The gap between "I could follow that" and "I could say that" is the entire point of an interview.

The scenario questions in file 04 are the ones that actually differentiate candidates at senior level. Anyone can recite the handshake; far fewer can say "connection refused is instant, a firewall drop hangs — so which was it?" and drive an investigation from there.

# Framer Motion (Motion)

**[Beginner → Advanced]** — a declarative animation library built for React: animation expressed as props (`initial`/`animate`/`exit`) that stay in sync with component state, rather than imperative calls. Part of the [[../README|frontend]] course.

## Structure

1. [[01-intro|01 — Intro]] — the `motion` component, the Motion rebrand, declarative vs. imperative
2. [[02-animate-props|02 — Animate Props]] — `initial`/`animate`/`exit`/`transition`, spring vs. tween
3. [[03-gestures|03 — Gestures]] — `whileHover`, `whileTap`, `whileInView`, `drag`
4. [[04-variants|04 — Variants]] — named states, propagation to children, orchestration (`staggerChildren`)
5. [[05-animate-presence|05 — AnimatePresence]] — making `exit` actually run before unmount
6. [[06-layout-animations|06 — Layout Animations]] — the `layout` prop, `layoutId` shared element transitions
7. [[07-scroll-animations|07 — Scroll Animations]] — `useScroll`, `useTransform`, `useSpring`
8. [[08-performance-and-gotchas|08 — Performance and Gotchas]] — `LazyMotion`, SSR, common "why isn't this animating" causes

# Glossary

Every abbreviation used across this vault, with what it stands for.

**You should rarely need this page.** Hovering over any acronym on the site shows
its meaning in a tooltip, generated automatically from this same list. The page
exists for two reasons: hovering does not work on a phone, and sometimes it is
useful to read the whole list at once.

If an acronym is missing a tooltip, it is missing from
`quartz-plugins/abbreviations/glossary.json` — add it there and it will work
everywhere at once.

## Deliberately not expanded

Some capitalised words look like acronyms and are not, so the tooltip skips them:

1. **AND**, **OR**, **NOT**, **NAND**, **XOR**: In [[how-computers-work/index|how computers work]] these are logic gates, and in [[databases/index|databases]] they are query keywords. Expanding them would be wrong in both places. (`XOR` *is* expanded, because "exclusive or" is genuinely what it abbreviates.)
2. **SELECT**, **INSERT**, **UPDATE**: These are SQL keywords, not abbreviations.
3. **ID**: Short for "identifier", but so common that a tooltip on every occurrence adds nothing.
4. **README**: A filename.

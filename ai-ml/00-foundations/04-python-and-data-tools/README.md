# 04 — Python & Data Tools

The hands-on foundation both the [[ai-ml/01-data-scientist/README|Data Scientist]] and [[ai-ml/02-ml-engineer/README|ML Engineer]] paths stand on: the Python numeric stack. Part of [[ai-ml/00-foundations/README|00-foundations]].

These are **practice notes** — code-heavy, meant to be typed out and run, not just read. They're the *how-to* companion to two more conceptual notes elsewhere: the [[ai-ml/02-ml-engineer/01-foundations-of-ml/02-the-ml-toolkit|ML Toolkit]] landscape (what each library is *for*) and the [[ai-ml/01-data-scientist/05-data-visualization|Data Visualization]] principles (which chart, and honesty). Written assuming you already program — they focus on the data-specific idioms, not Python basics.

1. [[ai-ml/00-foundations/04-python-and-data-tools/01-python-for-data|Python for Data]] — **[Beginner]** — the environment (Jupyter, venv), and the Python idioms that show up constantly in data code
2. [[ai-ml/00-foundations/04-python-and-data-tools/02-numpy|NumPy]] — **[Beginner → Intermediate]** — arrays, vectorization, and broadcasting: the mental shift from loops to array thinking
3. [[ai-ml/00-foundations/04-python-and-data-tools/03-pandas|pandas]] — **[Intermediate]** — the DataFrame: loading, selecting, grouping, joining, and cleaning real data
4. [[ai-ml/00-foundations/04-python-and-data-tools/04-visualization-basics|Visualization Basics]] — **[Intermediate]** — matplotlib and seaborn, hands-on

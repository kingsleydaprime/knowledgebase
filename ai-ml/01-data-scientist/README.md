# 01 — Data Scientist

The Data Scientist path is about **extracting insight and drawing sound conclusions from data** — framing questions, exploring and understanding data, running experiments, and using statistics and models to answer questions that inform decisions. Where the [[ai-ml/02-ml-engineer/README|ML Engineer]] ships a model as software and the [[ai-ml/03-ai-engineer/README|AI Engineer]] builds on pre-trained models, the Data Scientist's deliverable is usually an *answer, a recommendation, or a communicated finding*. Part of the [[ai-ml/README|AI/ML course]].

## What this track covers (and what it borrows)

roadmap.sh's [`ai-data-scientist`](https://roadmap.sh/ai-data-scientist) roadmap is deliberately high-level, and much of it — machine learning, deep learning, MLOps, mathematics — is already built in the [[ai-ml/02-ml-engineer/README|ML Engineer track]] and [[ai-ml/00-foundations/README|foundations]]. So this track focuses on the **distinctive DS pillars** (statistics, EDA, visualization, experimentation, causal inference) and cross-links the shared modeling rather than duplicating it.

## Reading order

1. [[ai-ml/01-data-scientist/01-the-data-scientist-role|The Data Scientist Role]] — **[Beginner]** — DS vs ML engineer vs analyst, the analytics spectrum (descriptive→prescriptive), the DS workflow, and why communication is half the job
2. [[ai-ml/01-data-scientist/02-descriptive-statistics|Descriptive Statistics]] — **[Beginner → Intermediate]** — central tendency, dispersion, distribution shape, and correlation — summarizing data honestly
3. [[ai-ml/01-data-scientist/03-inferential-statistics|Inferential Statistics]] — **[Intermediate]** — sampling, the CLT, confidence intervals, hypothesis testing, p-values, and the common tests
4. [[ai-ml/01-data-scientist/04-exploratory-data-analysis|Exploratory Data Analysis]] — **[Intermediate]** — the systematic "understand before you model" process
5. [[ai-ml/01-data-scientist/05-data-visualization|Data Visualization]] — **[Intermediate]** — choosing the right chart, the libraries and BI tools, and communicating without misleading
6. [[ai-ml/01-data-scientist/06-experimentation-and-ab-testing|Experimentation & A/B Testing]] — **[Intermediate → Advanced]** — designing experiments that give trustworthy answers
7. [[ai-ml/01-data-scientist/07-causal-inference-and-econometrics|Causal Inference & Econometrics]] — **[Advanced]** — correlation vs causation, confounders, regression for *inference*, and time series

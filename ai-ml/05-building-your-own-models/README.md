# Building Your Own Models

The last phase: designing an architecture rather than reusing one, deciding when that's actually justified over fine-tuning, and what happens after a model is trained — getting it into production and keeping it healthy there. This assumes everything in `ml-engineering/` and, for image-specific problems, `computer-vision/` as background.

## Reading order
1. [[01-designing-an-architecture|designing-an-architecture]] — **[Advanced]** — matching architecture family to data shape, depth/width, common building blocks (residual connections, normalization, attention)
2. [[02-training-from-scratch-vs-fine-tuning|training-from-scratch-vs-fine-tuning]] — **[Advanced]** — when training from zero is actually worth the enormous extra cost
3. [[03-deployment-and-mlops|deployment-and-mlops]] — **[Advanced]** — serving, monitoring for drift, versioning, retraining pipelines

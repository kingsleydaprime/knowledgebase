# Certifications & Career

**[reference]** — from the roadmap.sh cyber-security roadmap. The credential landscape and how the security career paths map to this course. Certs matter more in security than most of tech — many roles (especially government/defense) *require* them, and they're a common hiring filter.

## The career paths

Security isn't one job; the main tracks map onto this course's sections:

- **Offensive** (red team / penetration tester / ethical hacker) — [[cybersecurity/02-ethical-hacking/README|ethical hacking]] + [[cybersecurity/06-attacks-and-threats/README|attacks]].
- **Defensive / SOC analyst / blue team** — [[cybersecurity/07-security-operations/README|security operations]]: monitoring, detection, incident response. The largest employer of entry-level security talent.
- **DFIR** (incident responder / forensic analyst) — the deep end of [[cybersecurity/07-security-operations/05-forensics-and-malware-analysis|forensics & IR]].
- **Application / product security** — [[cybersecurity/04-web-security/README|web/app security]], secure coding, working with dev teams (a natural pivot for a software engineer).
- **Cloud security** — [[cybersecurity/09-cloud-security/README|securing cloud/infrastructure]], overlapping DevOps → "DevSecOps."
- **GRC / security management** — [[cybersecurity/08-governance-risk-and-compliance/01-risk-and-frameworks|risk, compliance, audit]], leading toward CISO.

For someone coming from software engineering, **application security** and **cloud/DevSecOps** are the most natural entries — they build directly on skills you already have.

## The certification landscape

Grouped by level and focus:

**Foundational / entry:**
- **CompTIA Security+** — the standard entry-level cert; broad fundamentals, widely required as a baseline. A sensible first cert.
- **CompTIA Network+ / A+ / Linux+** — the IT/networking foundation beneath security (much of it overlaps [[devops/01-linux/README|Linux]] and [[devops/08-networking-and-web/01-networking-and-protocols|networking]]).

**Offensive:**
- **CEH** (Certified Ethical Hacker) — broad, well-known, theory-heavy.
- **OSCP** (Offensive Security Certified Professional) — the respected, *hands-on* pentest cert with a grueling 24-hour practical exam. Hard to fake, highly valued.
- **PNPT, GPEN, GWAPT** — other respected practical/pentest certs.

**Defensive / blue team:**
- **CompTIA CySA+**, **GCIH** (incident handling), **GCFA** (forensics), **Blue Team Level 1/2** — SOC, IR, and forensics focused.

**Management / senior:**
- **CISSP** — the flagship senior/management cert (broad, requires experience); often a gate for security leadership roles.
- **CISM**, **CISA** — management and audit focused (GRC track).

**Cloud:** vendor security certs (AWS Security Specialty, etc.) plus the vendor-neutral ones.

## The honest advice

- **Certs open doors but don't replace skill.** OSCP is respected precisely because it's hands-on; a paper cert with no practical ability shows quickly. Pair certs with real practice — the [[cybersecurity/02-ethical-hacking/12-practice-exercises|labs and platforms]] (HackTheBox, TryHackMe, picoCTF, and building a [[cybersecurity/02-ethical-hacking/05-home-lab-setup|home lab]]) are where the actual capability comes from.
- **Match the cert to the path**: Security+ to get in the door, then OSCP (offensive) / CySA+ or GCIH (defensive) / CISSP (management) depending on direction.
- **For a developer**, the highest-leverage move is often *not* a cert first but *building secure things* and learning app/cloud security on the job — the same "reps over reading" principle as the rest of this vault ([[project-ideas|project ideas]]).

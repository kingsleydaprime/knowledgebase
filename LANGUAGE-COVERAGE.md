**What's excluded, and why:** the `languages/` courses (a Rust course is about Rust), project notes and journals (they record real work in the language it was done in), interview banks, and the NeetCode solutions.

**Order of work:** the lessons SWE 101, 102 and 103 send you to — core first — then everything else. Each companion is a batch of its own: every language's example runs in a lab before it's written down.

# Introduction to Software Engineering

## What software engineering is

**Software engineering is building software that real people rely on, as a team, in a way that keeps working and can keep changing for years.**

Programming is writing code that works. Software engineering is everything around that: deciding what to build, planning it, working with other people, testing it, releasing it, fixing it when it breaks, and changing it when needs change, often for years after it was first written. A small script you write for yourself is programming. A banking app used by millions, built by hundreds of people over ten years, is software engineering.

These four short notes explain what the job actually involves, the stages a piece of software goes through, the different roles on a team, and the different kinds of software engineering you could go into.

## What you'll be able to do

By the end you will be able to:
- explain the difference between programming and software engineering;
- name the stages software goes through, from idea to maintenance, and what goes wrong when one is skipped;
- explain what each role on a software team is responsible for;
- describe the different areas you could specialise in, and which are hard to move into later.
